# Classic Models Sales Analysis Dashboard

## 📊 Project Overview

This project presents an interactive **Sales Analysis Dashboard built in Microsoft Excel** using the Classic Models sales dataset.

The objective of this project is to transform raw sales data into meaningful business insights through **data cleaning, Pivot Tables, KPI analysis, and interactive dashboard visualizations**.

The dashboard enables users to analyze sales performance across different **product lines, countries, customers, order periods, and sales categories**.

---

## 🎯 Business Objective

The main objectives of this project are to:

* Analyze overall sales performance.
* Identify the best-performing product lines.
* Compare sales across different countries.
* Track sales trends over time.
* Analyze customer and order data.
* Create an interactive dashboard for faster business decision-making.
* Convert raw transactional data into clear and actionable insights.

---

## 📁 Dataset Information

The dataset contains **307 sales records** and includes the following key fields:

| Column          | Description                        |
| --------------- | ---------------------------------- |
| ORDERNUMBER     | Unique order identification number |
| CUSTOMERNAME    | Name of the customer               |
| OrderDate       | Date when the order was placed     |
| Month Name      | Month of the order                 |
| STATUS          | Current status of the order        |
| QUANTITYORDERED | Number of units ordered            |
| PRICEEACH       | Price per unit                     |
| SALES           | Total sales value                  |
| PRODUCTLINE     | Product category                   |
| PRODUCTCODE     | Unique product code                |
| CITY            | Customer city                      |
| COUNTRY         | Customer country                   |
| TERRITORY       | Sales territory                    |
| DEALSIZE        | Size/category of the deal          |

The dataset covers sales activity across **19 countries**, **92 customers**, and **60 products**.

## 🔍 Key Insights

### 1. Classic Cars Generated the Highest Sales

The **Classic Cars** product line generated approximately **$862.9K in sales**, making it the strongest-performing product category in the dataset.

This indicates that Classic Cars were the primary revenue driver.

### 2. USA Was the Largest Market

The **United States generated approximately $524.4K in sales**, making it the highest-performing country.

Other major markets included:

* France
* Spain
* Australia
* United Kingdom

### 3. Sales Performance Varied Across Product Categories

The top product categories included:

1. Classic Cars
2. Vintage Cars
3. Motorcycles
4. Planes
5. Trucks and Buses

This analysis helps identify which product categories contribute the most to overall revenue.

### 4. 2004 Recorded the Highest Sales

Sales by year showed:

| Year | Total Sales |
| ---- | ----------: |
| 2003 | $504,289.01 |
| 2004 | $654,842.91 |
| 2005 | $249,533.56 |

Based on the available dataset, **2004 recorded the highest sales performance**.
